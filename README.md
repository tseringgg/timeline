# Historical Timeline Web Application

## Description
This web application presents historical timelines in a graphical format. Users can explore historical events through an interactive UI, while authentication and authorization are managed using Microsoft Entra ID. It also features Stripe integration for payments.

## Features
- Interactive graphical timelines of historical events.
- Secure authentication and authorization.
- Payment system powered by Stripe.

## Tech Stack
- Angular (Frontend)
- ASP.NET Core (Backend)
- Azure SQL Database
- Microsoft Entra ID (Authentication)
- Stripe (Payments)
